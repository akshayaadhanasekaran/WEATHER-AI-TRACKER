# 🌦️ Weather AI Tracker

## AI-Driven Spatio-Temporal Tracking of Extreme Weather Anomalies

Weather AI Tracker is a prototype system designed to detect and track extreme weather anomalies using weather forecast data.

### 🚀 Main Features

- 🌧️ Extreme weather anomaly detection
- 🌀 Weather event tracking
- 📍 Anomaly location identification
- 📊 Weather data visualization
- 🤖 AI-based weather analysis
- 🔬 Future high-resolution weather downscaling

### 🎯 Project Goal

The goal of this project is to identify extreme weather anomalies, track their movement over time, and provide localized weather information through an interactive dashboard.

### 🛠️ Technologies

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Plotly
- SciPy
- Xarray

### 📌 Project Status

This is an initial prototype. AI-based anomaly tracking and high-resolution downscaling modules will be added in the next stages.
